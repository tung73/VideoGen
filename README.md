## Package

See [`iran_us_news_report/`](iran_us_news_report/) for the full briefing (as of 27 July 2026) with:

- Narrated situation report (TTS)
- 3D Persian Gulf / Strait of Hormuz situation map
- 3D conflict timeline graphic
- Lower-thirds, ticker, and segment cards

**Source output:** `iran_us_news_report/output/Iran_US_War_News_Report_27Jul2026.mp4`

python3 iran_us_news_report/generate_report.py
